Use the following lightweight Markdown-like markup in your paper content:

## 1. Introduction         → Heading 1
### 1.1 Background         → Heading 2
#### 1.1.1 Detail          → Heading 3

References                 → marks following items as reference entries
[1] Smith et al. …         → Reference item
1. Smith et al. …          → Reference item (numbered list)
